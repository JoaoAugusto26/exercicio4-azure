# Exercício 4 - Infraestrutura em Nuvem e Inteligência Artificial

Este repositório contém a resolução do Exercício 4, focado na implementação de soluções em nuvem utilizando a plataforma **Microsoft Azure**. O projeto abrange desde a criação de instâncias de bases de dados relacionais até a integração de serviços cognitivos de IA com aplicações Java.

## 🎯 Objetivos do Projeto
- Configurar e gerir recursos na nuvem através do portal Azure.
- Realizar o deploy de uma base de dados **PostgreSQL** e realizar acessos remotos.
- Consumir APIs de **Inteligência Artificial (Serviços Cognitivos)** para processamento de linguagem natural.

---

## 🚀 Estrutura da Entrega (Produtos)

### Produto 1: Configuração de Ambiente
- Ativação da subscrição **Azure for Students**.
- Criação do Grupo de Recursos estruturado para a disciplina.

### Produto 2: Base de Dados Relacional na Nuvem
- Implementação de um servidor **PostgreSQL Flexible Server**.
- Configuração de regras de firewall para acesso remoto.
- Ligação efetuada via **pgAdmin**, com criação de tabelas e manipulação de dados via SQL.

### Produto 3: Integração com Inteligência Artificial
- Criação de um recurso de **Azure AI Services** (Language Service).
- Desenvolvimento de uma aplicação em **Java** para consumo da API de **Análise de Sentimentos**.
- A aplicação comunica com o Ponto de Extremidade (Endpoint) da Microsoft para identificar a polaridade de textos de forma automatizada.

---

## 🛠️ Tecnologias e Ferramentas
- **Nuvem:** Microsoft Azure
- **Base de Dados:** PostgreSQL
- **Linguagem:** Java
- **IDE:** Eclipse
